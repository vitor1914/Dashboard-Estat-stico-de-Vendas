
# Dashboard Estatístico de Vendas | Sales Analytics Dashboard

**PT-BR:** Projeto de análise estatística e visualização de dados de vendas, desenvolvido com Python e Streamlit.

**EN:** A sales data analysis and visualization project built with Python and Streamlit.

---

## 🇧🇷 Português

### Sobre o projeto

Este projeto explora dados de vendas por meio de estatística descritiva, visualizações e um dashboard interativo. O objetivo é transformar dados brutos em informações úteis para análise e tomada de decisão.

### Funcionalidades

- Cálculo de média, mediana e moda.
- Análise de valores mínimos, máximos e amplitude.
- Indicadores de faturamento e quantidade vendida.
- Cálculo de desvio padrão e resumo estatístico.
- Gráficos de valores por registro e distribuição de vendas.
- Visualização da relação entre quantidade e valor.
- Filtro interativo por faixa de preço.
- Tabela de dados filtrados.
- Exportação dos dados filtrados para CSV.

### Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Streamlit

### Como executar

**1. Criar e ativar o ambiente virtual**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

**2. Instalar as dependências**

```bash
python -m pip install pandas matplotlib streamlit
```

**3. Executar o dashboard**

```bash
python -m streamlit run dashboard.py
```

O dashboard será disponibilizado em um endereço local exibido pelo Streamlit.
